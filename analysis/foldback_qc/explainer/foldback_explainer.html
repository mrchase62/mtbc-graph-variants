How fold-back chimeras make false SV calls

A fold-back chimera is a single library molecule that reads along the genome and then turns back on itself, continuing along the opposite strand. Aligned, it looks exactly like a read crossing an inversion breakpoint. When enough of these reads pile up at one spot, SV callers report a small inversion that is not in the genome.

What the read-removal experiment showed. In 9 chimeric libraries mapped to their own finished genomes, where every SV call is false, deleting only the fold-back read pairs (1.3–10.7% of pairs) removed 95% of our caller's false calls and 90% of dysgu's. Deleting the same number of random pairs removed none.

1

The molecule folds back during library prep

Fragmenting DNA leaves ends with single-stranded stretches. If a single-stranded 3′ end contains one arm of an inverted repeat (a short sequence whose reverse complement occurs nearby), it can pair with the other arm. A polymerase in end repair or gap filling then extends that 3′ end, using the strand it has paired with as a template. The new sequence is a copy of the opposite strand, attached directly to the original strand. Haile et al. (2019) traced chimeric reads of this kind, which they called strand-split artifact reads, to single-stranded DNA in sonicated FFPE libraries. Chen et al. (2024) found the same in enzymatically fragmented libraries.

Where the template comes from sets the distance

The paired arm can sit on the same molecule or on a different copy of the same region. The two cases leave different footprints in the alignment.

Self-priming. The 3′ end folds back onto its own strand and pairs with an arm upstream of it. The polymerase then copies sequence the read has already covered, so the two pieces of the read align on top of each other. This is the tight hairpin that dominates most of these libraries.

Pairing with a second copy. Chen et al. describe a model they call PDSM (pairing of partial single strands derived from a similar molecule). The 3′ end pairs with a single strand from another fragment of the same region, which can reach beyond where the first fragment ended. The copy then starts downstream, and the second piece lands past the first with a gap about as long as the distance between the arms. That would explain the spaced pieces in N1176, though we have not tested which route dominates there.

The aligner splits the read across both strands

bwa aligns the first part of the read on one strand and the second part on the other strand a short distance away. The second part is recorded as a supplementary alignment (the SA tag), or, when it is too short to place, as a soft clip. Below is a real read from isolate N1176, a 151 bp Tn5 library.

The same read laid out base by base shows what the aligner did at the junction. Read bases 75–79 are in both alignments. Assuming those bases match the reference without mismatches, positions 619–623 on the + strand are the reverse complement of positions 1,197–1,201, about 575 bp apart. That 5 bp match is a candidate for the inverted-repeat arm that held the molecule together.

The distance between the two pieces depends on the library. In most of these libraries the second piece lands back on top of the first (a tight hairpin, pieces overlapping). In N1176, the worst library, it usually lands 100–600 bp away (a wider loop).

Four forms a fold-back takes in a BAM

Where the junction falls within the sequenced fragment decides how it shows up.

Split read

The junction falls inside a read and both pieces are long enough to place. Primary alignment plus an SA tag on the same contig, opposite strand, usually within 1 kb.

Soft clip only

One piece is too short for the aligner to place (roughly under 20–30 bp), so there is no SA tag. Reverse-complement the clipped bases and look for them within a few hundred bp of the clip, including inside the aligned part of the read.

Same-strand pair

The junction falls in the unsequenced middle of the fragment. Neither read is split, but both mates map to the same strand (FF or RR) close together. Callers count these as discordant pairs for an inversion.

Overlapping pieces

The second piece aligns on top of the first, in reverse. A real inversion junction joins sequence outside the inverted segment to sequence inside it, so its pieces cannot overlap by more than a few bases of microhomology. Large overlap is the most specific single sign of a fold-back.

Sketch: flag split fold-back reads with pysam

A starting point for inspecting a BAM by hand. It is not the fold-back scan used for the numbers on this page, which also handles soft clips and pairs.

import re, pysam

REF_LEN = re.compile(r"(\d+)([MDN=X])")

def foldback_gap(read, max_dist=1000, min_mapq=20):
    """Gap in bp between a read's primary and an opposite-strand SA piece
    on the same contig (negative = the pieces overlap). None if no such piece."""
    if read.is_unmapped or read.is_secondary or read.is_supplementary:
        return None
    if not read.has_tag("SA"):
        return None
    for sa in read.get_tag("SA").rstrip(";").split(";"):
        chrom, pos, strand, cigar, mapq, _nm = sa.split(",")
        if chrom != read.reference_name or int(mapq) < min_mapq:
            continue
        if (strand == "-") == read.is_reverse:
            continue                      # same strand: deletion/duplication signal
        start = int(pos) - 1
        end = start + sum(int(n) for n, _ in REF_LEN.findall(cigar))
        gap = max(read.reference_start, start) - min(read.reference_end, end)
        if gap <= max_dist:
            return gap
    return None

def same_strand_pair(read, max_dist=1000):
    return (read.is_paired and not read.mate_is_unmapped
            and read.reference_id == read.next_reference_id
            and read.is_reverse == read.mate_is_reverse
            and abs(read.next_reference_start - read.reference_start) <= max_dist)

with pysam.AlignmentFile("sample.bam") as bam:
    for r in bam.fetch("NZ_CP069069.1", 500, 1500):
        g = foldback_gap(r)
        if g is not None:
            print(r.query_name, r.reference_start, g)

Callers read the split as an inversion

An SV caller collects reads whose pieces join opposite strands, clusters them by position, and calls an event once enough reads agree. Opposite-strand joins within a few hundred bases are the signature of a small inversion, so that is what comes out. The size reported is roughly the distance between the two pieces.

The difference from a real inversion is in what the other reads at the site show. At a real inversion every read that spans the breakpoint carries the join, there is a matching second breakpoint, and read depth is normal. At a fold-back junction only a few reads carry the join and every other read shows the reference.

Checks at a called site

When a small inversion is called, these site-level checks separate the two. Mtb is haploid and clonal, so a real inversion should be carried by nearly every read across it unless the sample is a mixed infection.

The calls that disappeared when the fold-back reads were removed are almost all inversions (or our caller's unpaired breakends, which are the same signal without a partner). Nearly all are 50–500 bp.

4

Recurrence turns noise into a call

A single fold-back read is ignored: callers need several reads supporting the same junction. What stacks reads at one junction is the sequence.

Sequence hotspots. Many junctions hold 5 or more independent molecules. Those sites are enriched for inverted repeats, the sequence that lets the end fold back in step 1.

Not PCR copies (corrected 2026-10-11). An earlier version of this page said PCR duplicates inflate the hotspots. A direct test refuted it: fold-back pairs are duplicated no more often than other pairs (N0004 32% vs 43%; N1176 6.7% vs 6.0%), and removing duplicates raised dysgu's false calls (3,999 to 4,862) instead of lowering them. Duplicate removal takes ordinary reads away at least as fast as chimeric ones, so the chimeric share at each site goes up.

5

Why an allele-fraction floor is not enough

The allele fraction a caller reports is the share of reads at the site carrying the join. At a hotspot that can easily reach 10–20%, and dysgu, which counts reads differently, sometimes reports 50% or more. A 10% floor removes about half of our caller's fold-back calls; a 20% floor removes most of ours but leaves 1,703 dysgu calls in these 9 libraries.

6

Removing the fold-back reads removes the calls

Each library was run four ways: all reads; half of the fold-back pairs removed; all of them removed; and the same number of random non-fold-back pairs removed, which controls for the loss of depth. Insert size, library, genome and everything else stayed the same.

What this means for the pipeline

Small inversions and unpaired breakends from short reads are the calls to distrust; the agreed robust tier already leaves them out. Sample QC should catch libraries with many recurrent junctions, which the fold-back rate tracks well and the count of recurrent junctions may track better. The selfcal54 isolates will test where the false calls start, and whether insert size or junction recurrence adds to the rate.
